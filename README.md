## Kurulum

Herhangi bir bağımlılık gerekmez. Dosyaları doğrudan tarayıcıda açabilirsiniz:

```bash
# index.html dosyasını tarayıcıda açın
start index.html
```

Veya bir local server ile:

```bash
npx serve .
```
